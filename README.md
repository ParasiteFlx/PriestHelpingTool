# PriestHelpingTool

EN : The purpose of the app is to help a priest with his schedule. This was a team project. The app has a layered architecture with the MVC(Model‑View‑Controller) model being used for the outer layers, while the Service‑Repository pattern was used for data logic and persistence. The application also has an generic CRUD functionality implemented using Java Generics, significantly reducing boilerplate code. For the GUI, I used Java Swing. During the development, we adhered to the SOLID and DRY (Don’t Repeat Yourself) principles. We also created UML diagrams.
     
RO: Scopul aplicației este să ajute un preot cu orarul său. Acest proiect a fost unul de echipă. Arhitectura este stratificată(layered) și este bazată pe modelul MVC(Model‑View‑Controller) în straturile superioare și extins cu Service‑Repository în cele inferioare pentru a asigura persistența datelor și prelucrarea facilă a acestora. Pentru a reduce redundanța codului, ne‑am folosit de Java Generics pentru a crea un CRUD universal. Cât despre interfață, aceasta a fost creată cu Java Swing. În final, pe parcursul dezvoltării am ținut cont de principiile SOLID și am făcut și diagrame UML corespunzătoare.
